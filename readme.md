# [えあ・ぎたー](https://protopedia.net/prototype/7707)
### 作ったきっかけ
### 1.テクノロジーとエンタメのあり方
* 最近生成AIで、**音楽を制作する、** **アニメーションを作る、画像を作る**というただ**自動化または生産して終わりのような作品が多く**、**テクノロジーとエンターテイメントの融合**というのには少し距離があるような感じがあり、**実際の楽器の演奏を支援してくれるようなシステムを作ることはできないだろうかという思いから作りました。** 

### 2.個人的な思い

* 私は、ギターを趣味にしており**高校時代軽音部で即席でギターを弾きたいけどハードルが高い**という部員の意見などがありそのような**ギター初心者が「ちょっとギターを試してみたい」「気軽に演奏したい」** という思いに応えられないかとも思いました。
* 実際私の周りは楽器ができる人がいなくて、セッションもしづらい状況でした。**もっと簡単にみんなとセッションがしたい**という気持ちもあり作りました。

### 1. ギターコードを押さえる機構（アクチュエータ技術）

本システムの中核は、**ギターが演奏できない人でも演奏ができるようになる**ために、物理的にギターの弦を押さえる機構です。

*   **機材の使用**: **サーボモーター**と**PCA9685**が使用されています。
*   **機構の詳細**: ギターのコードを押す機構を作る際に苦労がありましたが、当初検討されたソレノイドでは**パワーが足りない可能性**があったため、**サーボモーターを使ったカム機構**に設計が変更されました（シャフト）。
*   **用途**: これらのアクチュエータは**本物のギターに搭載**され、Webサイトからの指示に従って、フレットを押さえる役割を果たします。
*   **成果**: この技術により、具体的に**大抵のオープンコードをおさえられるようになった**ことが達成事項として挙げられています。

### 2. 遠隔制御と通信技術

ユーザーの操作をギターの動作に結びつけるために、遠隔操作の技術が利用されています。

*   **入力方法**: **Webサイトからボタンを押して**、押さえたいコードを入力します。
*   **通信プロトコル**: この遠隔操作を可能にするために、**MQTT**という通信プロトコルが使用されています。開発者は、**MQTTの使い方をざっくりと理解できた**ことが技術的な達成事項として示されています。
*   **制御機器**: **raspberry pi**や**PC**といった機材がシステム制御に使用されています。

### 3. ソフトウェアとプログラミング

システムを駆動させるためのプログラミング言語が使われています。

*   **言語**: **Python**と**C言語**が使用されています。
*   **成果**: 開発を通じて**C言語を学べた**ことが達成事項の一つとされています。これは、Raspberry Piを用いたハードウェア制御や、効率的な動作プログラム作成に使用されたと考えられます。

### 4. 演奏タイミングの検知技術

コードが押さえられた状態で、いつギターを鳴らすか（ストロークのタイミング）を判断する技術です。

*   **使用技術**: **カメラ**が使用されています。
*   **用途**: カメラで演奏者の**ストロークを検知**します。
*   **機能**: この検知情報に基づき、システムはアクチュエータがコードを押さえている状態で**ギターを鳴らす**動作を実行します。
*   **今後の課題**: 今後、**ストロークの解像度をもう少し上げていきたい**と**色々なギターコードを押さえれるようになる**という2つの目標が示されており、検知精度の向上が課題とされています。

まとめると、このシステムは、**Webサイト**から入力されたコード情報を**MQTT**で伝送し、**raspberry pi**が**PythonやC言語**で制御を行うことで、**サーボモーター（カム機構）**に指示を出し、物理的にギターのフレットを押さえます [1, 会話履歴]。そして、ユーザーがストロークするタイミングを**カメラ**で検知することで、自動的にコード演奏が実現される仕組みとなっています。
